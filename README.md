# Tower Of Desire (working title) - 18+ game, Godot 4.x

Adults-only 2D turn-based game. All characters are adults (18+).

## Run
1. Install Godot 4.2+ (free): https://godotengine.org/download
2. Open Godot -> Import -> select `project.godot` -> press F5.

## Add content without coding
- `data/actions.json` - attacks, cooldowns, unlock stage
- `data/enemies.json` - enemy types and colors
- `data/stages.json`  - rooms and enemy lineup
- `data/character_options.json` - creator options
